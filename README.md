# Datheon Python Programming Internship

A modular, clean, and beginner-accessible Python project implementing all four tasks assigned during the Datheon Python Programming Internship. Built entirely using the Python standard library, this repository emphasizes correctness, input validation, modular architecture, comprehensive automated testing, and safe operational defaults.

---

## Overview of Tasks

1. **Task 1: Hangman Word Guessing Game (`hangman.py`)**  
   An offline terminal word-guessing game featuring:
   - Built-in English word dictionary.
   - Dynamic 7-stage ASCII gallows art progression.
   - Exact 6-mistake allowance before defeat.
   - Single-character validation, repeated-letter support, and duplicate-guess protection (no penalty for repeated letters).
   - Graceful game exit via `QUIT`.

2. **Task 2: Stock Portfolio Performance Tracker (`portfolio.py`)**  
   An investment portfolio performance calculator that:
   - Computes total invested capital, current market value, profit/loss, and percentage return for individual holdings and the aggregate portfolio.
   - Loads illustrative demonstration prices from `sample_data/portfolio_prices.csv`.
   - Distinguishes demo values from live quotes, with manual entry/override support.
   - Exports formatted summaries to `portfolio_summary.csv` using Python's built-in `csv` module.
   - Protects against division-by-zero and negative price inputs.

3. **Task 3: Automated File Organizer (`organizer.py`)**  
   A safe file organization utility that:
   - Scans files in a selected directory (non-recursive to protect subfolders).
   - Categorizes common extensions into `Documents`, `Images`, `Videos`, `Archives`, `Code`, and `Audio`.
   - Displays a dry-run preview before touching any files.
   - Requires explicit user confirmation (`YES`) before executing moves.
   - Safely resolves naming collisions (e.g., `file_1.txt`) to prevent data loss.
   - Never deletes files and leaves unknown extensions untouched.

4. **Task 4: Rule-Based Interactive Chatbot (`chatbot.py`)**  
   A terminal customer support assistant that:
   - Normalizes input text and leverages regular expressions (`re`) with word boundaries (`\b`).
   - Supports 11 core customer support intents: Greetings, Business Hours, Product FAQs, Pricing, Payment Methods, Order Tracking, Delivery Information, Returns/Refunds, Contact Information, Thanks, and Goodbye.
   - Recognizes multiple intents in compound inquiries without duplicate answers.
   - Differentiates explicit exit commands (`exit`, `quit`, `bye`) from general questions containing exit words.
   - Uses fictional demonstration policies with friendly fallback prompts.

## Running the Programs

Run any program using your standard Python launcher from the project root directory:

### Task 1: Hangman Game
```powershell
python hangman.py
```
- **Example Inputs**: Type single letters such as `e`, `a`, `t`, or type `QUIT` to exit at any time.

### Task 2: Stock Portfolio Tracker
```powershell
python portfolio.py
```
- **Example Inputs**:
  - Enter ticker symbol: `TEST`
  - Shares: `5`
  - Purchase price: `100`
  - Current price: Accept sample price `120` or enter manual price.
  - Finish session: Enter `DONE`.
  - The script displays an aligned terminal summary table and writes `portfolio_summary.csv`.

### Task 3: Automated File Organizer
```powershell
python organizer.py
```
- **Safety Warning**: Always test on a temporary or sample folder first.
- **Example Inputs**:
  - Enter path: e.g., `C:\Users\Username\Downloads\test_folder`
  - Review dry-run preview.
  - Type `YES` to confirm move, or any other input to cancel safely without changes.

### Task 4: Customer Support Chatbot
```powershell
python chatbot.py
```
- **Example Inputs**:
  - `Hello! What are your business hours?`
  - `How can I track my order and what payment methods do you accept?`
  - `Type 'exit', 'quit', or 'bye' to end the session.`

## Demonstration Data & Safety Notices

1. **Demonstration Stock Prices (`sample_data/portfolio_prices.csv`)**  
   Prices provided in `portfolio_prices.csv` are illustrative demonstration figures intended for testing calculation mechanics. They do not represent live market data or financial advice.

2. **File Organizer Safety Protocols**  
   - Non-recursive: Nested subdirectories are left untouched.
   - Dry-Run Preview: Full planned moves and skipped items are displayed before filesystem modifications.
   - Explicit Confirmation: Only typing `YES` executes moves.
   - Collision Avoidance: Existing files are never overwritten; duplicate names are safely renamed with numbered suffixes (e.g., `photo_1.jpg`).
   - Zero Deletion: No files are ever deleted.
